# eco-by-different

System performance, encoding and compression optimization.

## Projects

### SmartTAR - STAR
- https://github.com/eco-by-different/smarttar-star
- Windows PowerShell GUI archiver
- Transparent `.star` archive containers based on Windows `tar.exe`
- Block manifest, SHA-256 verification and recovery-friendly design
- Smart compression planning with Balanced, Smart, Solid and Store modes

---

### WinZSTD
- https://github.com/eco-by-different/winzstd
- Native Windows TAR/TAR.ZST compression GUI
- Designed for easy archive creation from files and folders
- No external binaries required

---

### Low Bitrate Encoding
- https://github.com/eco-by-different/low-bitrate-encoding
- Efficient video encoding workflows (~100 MB/hour)
- AviSynth + x264 optimization

---

### AI RAM Engine
- https://github.com/eco-by-different/ai-ram-engine
- CPU, memory and power optimization tool
- Designed for heavy workloads, for example encoding
